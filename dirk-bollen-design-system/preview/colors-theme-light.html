Design System · Colors

Light Theme Tokens

Semantic aliases that drive component styling on white backgrounds. Use --fg, --bg, --accent etc. in components — never raw hex values.

Semantic Surface Tokens

Background

--bg → #FFFFFF

Background Muted

--bg-muted → #F2F2F2

Foreground

--fg → #211B43

Foreground Muted

--fg-muted → #747070

Border

--border → #E6E6E6

Border Strong

--border-strong → #211B43

Semantic Accent Tokens

Accent (primary CTA)

--accent → --db-pink · #EE4280

Accent Alt (present/today)

--accent-alt → --db-cyan · #45C4D9

Accent Warm (spark)

--accent-warm → --db-yellow · #FDC40D

Accent Deep (AI/synthesis)

--accent-deep → --db-purple · #7460AB
