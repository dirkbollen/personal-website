Design System · Spacing

Shadows & Elevation

The system is vector-flat. Shadows are used only to lift interactive cards off a canvas background. Do not add shadows to diagram elements, section headers, or illustration shapes.

Shadow Scale

--sh-0

none

Flat elements, diagram shapes, inline components

--sh-1

0 1px 2px rgba(0,0,0,0.06)

Default resting card

--sh-2

0 2px 8px rgba(0,0,0,0.08)

Hover state, elevated card

--sh-3

0 8px 24px rgba(0,0,0,0.10)

Modal, dropdown, focused panel

Usage Rules

  • Use --sh-0 (no shadow) for diagram elements, section backgrounds, and hero blocks
  • Use --sh-1 as the default resting state for all cards
  • Upgrade to --sh-2 on hover (translateY(-2px) + --sh-2)
  • Use --sh-3 only for overlays: modals, popovers, dropdowns
  • Never stack shadows — choose one level and stay there
  • Never use coloured shadows — always neutral rgba black
