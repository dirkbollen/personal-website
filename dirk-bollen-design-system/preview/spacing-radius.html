Design System · Spacing

Radius & Borders

The system leans flat. Use 0 for diagram blocks, 4px for subtle lifts, 10px for cards, 999px (pill) for tags and buttons. Avoid mid-radii (6–8px).

Border Radius Scale

--r-0 0px Blocks, diagram shapes, hero panels
--r-sm 4px Inputs, subtle card lift
--r-md 10px Soft cards, modals
--r-lg 20px Feature panels
--r-pill 999px Tags, chips, CTAs, buttons
--r-full 50% Avatars, dot indicators

Border Widths

--bw-hair 1px solid — dividers, table rules
--bw-1 2px solid — secondary outlines
--bw-2 3px solid — primary border weight (diagram shapes, cards)
--bw-2 --bs-dashed 3px dashed --dash — lines of visibility, uncertainty zones
--bw-4 5px solid — emphasis accent borders
