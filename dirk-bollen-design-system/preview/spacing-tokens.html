Design System · Spacing

Spacing Scale

4px base, 10-step scale. Section gutters use --s-9 (96px). Component padding uses --s-4 to --s-6. Inline gaps use --s-2 to --s-3.

Scale Reference

--s-1 4px Inline micro gaps, icon padding
--s-2 8px Tight gaps, badge spacing
--s-3 12px List item gaps, card inner padding
--s-4 16px Default paragraph margin, compact card padding
--s-5 24px Card padding, blockquote indent
--s-6 32px Section sub-spacing, grid gap
--s-7 48px Page horizontal padding, preview padding
--s-8 64px Large component gaps, slide margins
--s-9 96px Section vertical rhythm (primary)
--s-10 128px Hero vertical padding, wide sections
